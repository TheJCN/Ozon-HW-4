# Домашнее задание № 4: SQL и базы данных

Проект содержит PostgreSQL в Docker, скрипт создания таблиц с тестовыми
данными и отдельный SQL-файл для каждого задания.

## Как запустить

Нужен запущенный Docker Desktop. В WebStorm откройте этот README и нажмите
зелёный треугольник слева от нужного блока `shell`. Сначала запустите базу,
а затем — любое задание.

### 1. Запустить базу данных

```shell
docker compose up -d --wait
```

При первом запуске автоматически выполняется [`setup.sql`](setup.sql):
создаются таблицы `users` и `orders`, после чего добавляются тестовые данные.

### 2. Запустить нужное задание

#### Задание 1

```shell
docker compose exec -T db psql -U postgres -d ozon_hw4 -f /sql/task1.sql
```

#### Задание 2

```shell
docker compose exec -T db psql -U postgres -d ozon_hw4 -f /sql/task2.sql
```

#### Задание 3

```shell
docker compose exec -T db psql -U postgres -d ozon_hw4 -f /sql/task3.sql
```

#### Задание 4

```shell
docker compose exec -T db psql -U postgres -d ozon_hw4 -f /sql/task4.sql
```

#### Задание 5

```shell
docker compose exec -T db psql -U postgres -d ozon_hw4 -f /sql/task5.sql
```

### Остановить базу данных

Данные сохранятся и будут доступны при следующем запуске.

```shell
docker compose down
```

### Полностью пересоздать базу

Команда удалит учебную базу вместе с её Docker-томом, затем создаст её заново.

```shell
docker compose down -v && docker compose up -d --wait
```

## Ответы

### Задача 1: Долгожитель

Запрос находится в [`task1.sql`](task1.sql). Максимальный возраст сначала
определяется подзапросом, поэтому при совпадении возраста выводятся все самые
старые пользователи, а не один случайный пользователь.

Ответ:

| name  | age |
|-------|----:|
| Борис | 40  |
| Вера  | 40  |

### Задача 2: Перепись населения

Запрос находится в [`task2.sql`](task2.sql). Пользователи группируются по
городу, `HAVING` оставляет города с численностью больше одного человека.

Ответ:

| city    | user_count |
|---------|-----------:|
| Москва  | 3          |
| Казань  | 2          |

### Задача 3: Учёт трат

Запрос находится в [`task3.sql`](task3.sql). `LEFT JOIN` сохраняет
пользователей без заказов, а `COALESCE` заменяет отсутствующую сумму на `0`.

Ответ:

| name  | total_spent |
|-------|------------:|
| Борис | 120000      |
| Глеб  | 57000       |
| Анна  | 51500       |
| Егор  | 38000       |
| Дина  | 0           |
| Вера  | 0           |

### Задача 4: Любители музыки

Запрос находится в [`task4.sql`](task4.sql). `DISTINCT` убирает повторное имя
Егора, у которого есть два заказа с наушниками.

Ответ:

| name |
|------|
| Глеб |
| Егор |

### Задача 5: Бюджетный выбор

Запрос находится в [`task5.sql`](task5.sql). Подзапрос находит минимальную цену
среди заказов дороже 10 000 рублей. Сравнение по цене сохраняет все товары с
одинаковой минимальной стоимостью, если таких товаров несколько.

Ответ:

| item      | price |
|-----------|------:|
| наушники  | 12000 |
